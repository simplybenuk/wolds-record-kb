# Vet practices directory

Maintain a reusable list of veterinary contacts for referrals and reports.

## Add a vet practice

From **Vet practices**:

1. Select **Add vet practice**.
2. Enter **Practice name** (required).
3. Optionally add address, email, phone, vet name, and notes.
4. Select **Create vet practice**.

## Use in workflows

Assigned vet practices can be linked to dog records and reused in report workflows.
