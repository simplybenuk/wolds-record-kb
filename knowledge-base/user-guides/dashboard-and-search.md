# Dashboard and search

The dashboard and top navigation provide:

- **Global search** in the top navigation
- a **Get started** checklist for new organisations
- **Upcoming appointments**, for organisations with Calendar (beta)
- a **Recent sessions** overview
- the **Start a new session** launcher

## Get started checklist

Until you finish setting up, the dashboard shows a **Get started** card. Each
step ticks itself off when you complete it, and the card disappears when every
step is done.

The steps you see depend on your role and plan:

| Step | Shown to |
| --- | --- |
| Add your practice information, terms and privacy notice | Owners and admins |
| Add your first client | Everyone except read-only members |
| Add your first dog | Everyone except read-only members |
| Preview and share the owner consent form | Everyone except read-only members |
| Record your first session | Everyone except read-only members |
| Add your practice branding | Owners and admins on Pro |

To hide the card before you finish, select **Hide checklist**. This is
remembered in the current browser only, so the card shows again in another
browser or after you clear your browser data.

## Search clients and dogs

Use the search control in the top navigation from any signed-in page.

1. Enter at least 2 characters in the search box.
2. Review matching clients and dogs.
3. Select a result to jump directly to that record.

If many results exist, refine your query for a narrower list.

## Start a new session from the dashboard

Select **New Session** on the dashboard to open the **Start a new session**
launcher.

1. In **Search client or dog**, enter part of the client or dog name.
2. Select the matching dog and case from the list.
3. The new session editor opens for that case.

## Review recent sessions

Use the recent sessions table to quickly navigate to:

- Client record
- Dog record
- Session detail

This is helpful for daily follow-ups and continuity of care.
