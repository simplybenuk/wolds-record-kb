# Vet reports

Use vet reports to generate practitioner-to-vet summaries from session and case data.

## Open a vet report

1. Open a session.
2. Select **Vet report**.

## Report sections

- **Pre-session notes**: past medical history and current medication
- **Letter intro**
- **Reason for session**
- **Assessment findings**
- **Therapy session**
- **Treatment & rehabilitation plan**
- **Letter sign off**

## Save and export

- Save report changes before sharing.
- Use print/export actions to produce a shareable output.
- If PDF generation is unavailable, browser print is used as fallback.
