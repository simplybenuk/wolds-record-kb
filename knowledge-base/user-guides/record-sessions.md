# Record treatment sessions

## Create a new session

You can start a new session from a case page or from the dashboard:

- **From a case page**: select **Create session**.
- **From the dashboard or sessions list**: select **New Session**, then search for the client or dog under **Search client or dog** and choose an open case.

### Required

- **Session date/time**

### Common fields available

- Session location
- Changes since last session
- New veterinary investigations
- Guardian concerns
- Current medication
- Posture and movement observations
- Palpation and neurological notes
- Problem list and clinical impression
- SMART goals and treatment plan
- Aftercare and home therapy guidance
- Follow-up recommended date

## Session workspace

The session editor includes a context rail to keep case/dog/client context visible while writing notes.

## Save behavior

Select **Save** to save the session. If required fields are missing, inline errors are shown before save completes.
