# Record treatment sessions

## Create a new session

From a case page, select **Create session**.

The session opens in your organisation's **Default session form**. To use the
other form for this session, change **Session form type** under **Session
details** before you save. If you have entered notes in fields the other form
does not use, the app asks **Switch session form?**, because those fields are
cleared. Select **Switch form** to continue or **Keep current form** to stay.

New organisations default to **Brief session note**. Owners and admins can
change the default in
[Organisation settings](organisation-settings-and-export.md#organisation-settings).

### Required

- **Session date/time**

### Fields in every session

- **Location**
- Pre-session updates on veterinary investigations, guardian concerns,
  medication and other changes, shown once the case has an earlier session
- **Follow-up recommended date**

### Brief session note

- **Assessment summary**
- **Treatment provided**
- **Homecare & next steps**

### Full session note

- Posture and gait analysis
- Dynamic movement assessment
- Hands-on assessment, including palpation observations and range of motion
- Functional measures, including neurological notes
- Clinical reasoning: problem list, clinical impression, SMART goals and
  treatment plan
- **Techniques & modalities used**, including **Adverse reactions or
  responses**
- **Rehabilitation & owner guidance**, including aftercare advice and home
  therapy plan

## Session workspace

The session editor includes a context rail to keep case/dog/client context visible while writing notes.

## Save behavior

Select **Save** to save the session. If required fields are missing, inline errors are shown before save completes.
