# Common access and error messages

## "No active organisation"

Your account is not currently set to an active organisation. Re-run onboarding or switch organisation.

## "Access denied" / redirected to unauthorized

Your user is not a member of that organisation or does not have access to that route.

## "Missing ... details"

A required route parameter or record context was not found (for example client, dog, case, or session id).

## Save failures

When a save fails:

1. Check required fields first.
2. Retry after confirming your session is still active.
3. If still failing, capture the on-screen error and email support at <support@woldsrecord.com>.
